THE SCRIPTURES — WEBSITE STARTER

Files:
- index.html: the website
- manifest.json: installable web-app settings
- sw.js: offline shell caching

To preview:
1. Open index.html in a browser (some offline/install features require hosting).
2. For install and service-worker support, upload the folder to a static web host using HTTPS.

Bible content:
- The starter includes sample passages from Genesis 1, John 1, Psalm 23 and Matthew 5.
- Other chapters are loaded from bible-api.com when online and cached on the device after opening.
- Offline reading works for the starter passages and chapters previously loaded while online.

This is a starter website, not yet a complete published website or a full offline Bible database.
